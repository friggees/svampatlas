# Källor och verifieringsnivå

Kontrollerade 2026-09-27. Länkarna är primärkällor för teknik och dataåtkomst. Att en dokumentationssida är åtkomlig bevisar inte att ett konto, API-avtal eller datauttag fungerar. Inga produktions-API:er för svampdata har anslutits i denna planering.

| Källa | Vad den används för |
|---|---|
| [Next.js Server and Client Components](https://nextjs.org/docs/app/getting-started/server-and-client-components) | Renderings- och klientgränser |
| [Supabase SSR-klienter](https://supabase.com/docs/guides/auth/server-side/creating-a-client) | Auth, cookies och sessionshantering |
| [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security) | Databasens radbehörigheter |
| [Supabase PostGIS](https://supabase.com/docs/guides/database/extensions/postgis) | Spatiala typer, index och frågor |
| [Supabase changelog](https://supabase.com/changelog) | Kontroll av plattformsändringar inför implementation |
| [shadcn/ui](https://ui.shadcn.com/docs) | Komponenter och designgrund |
| [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/) | Kartrenderare |
| [OSM tile-policy](https://operations.osmfoundation.org/policies/tiles/) | Villkor för publika standardtiles |
| [SLU:s API:er](https://www.slu.se/artdatabanken/rapportering-och-fynd/oppna-data-och-apier/om-slu-artdatabankens-apier/) | Artinformation och observationsdata |
| [SLU API-frågor](https://www.slu.se/artdatabanken/rapportering-och-fynd/oppna-data-och-apier/faq-om-vara-apier/) | Kompletterande information om dataåtkomst |
| [Nationella marktäckedata](https://www.naturvardsverket.se/verktyg-och-tjanster/kartor-och-karttjanster/nationella-marktackedata/) | Marktäcke som habitatunderlag |
| [SMHI Open Data](https://opendata.smhi.se/) | Väderdatadokumentation |

Artprofiler, habitatvikter, ätlighetsinformation och juridiska påståenden är inte färdiggranskade i detta dokumentpaket. De behöver separata aktuella källor och relevant granskning innan produktpublicering. Arkitekturval, tidsuppskattningar, testmål och föreslagna modellmetoder är projektförslag, inte påståenden från källorna.
